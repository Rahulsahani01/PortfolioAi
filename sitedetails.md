# Portfolio Builder – User Information Form

This form collects the minimum information required to generate a professional portfolio website. Only ask for the fields below to keep the onboarding process quick and user-friendly.

---

## 1. Personal Information

### Full Name *
The user's full name as it should appear on the portfolio.

**Example**
```
Rahul Sahani
```

---

### Professional Title *
A short title describing the user's profession.

**Example**
```
Backend Software Engineer
Full Stack Developer
UI/UX Designer
Product Manager
```

---

### Professional Summary (About Me) *
A concise summary highlighting the user's background, expertise, and career goals.

**Guidelines**
- 100–300 words
- Focus on professional experience and strengths
- Avoid personal hobbies unless relevant

**Example**
```
Backend Software Engineer with 2+ years of experience building scalable SaaS applications using Node.js, PostgreSQL, and React. Passionate about designing secure APIs, optimizing database performance, and creating reliable backend systems.
```

---

### Profile Photo (optional)
Upload a professional profile picture.

**Accepted Formats**
- JPG
- PNG
- WEBP
